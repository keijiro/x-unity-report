X 日本 Unity 関連ポストまとめ - 2026-05-25 (月)

1. 全体サマリー

この日の日本語 Unity 関連 TL は、「Unity 終わるのか論争」と「VRChat アバター改変・Unity 撮影ブーム」の二大潮流が支配的だった。前者は mizchi 氏の「Unity と心中しようとしてる人、かつての Flash から何も学んでないな」という挑発的ポストが起点となり、Godot/UE6 への移行論、AI コーディングとの相性論まで巻き込んで日中ずっと燻り続けた。後者は LimbusCompany_B 公式の Unity バージョンアップ告知 (1689 likes) でゲーマー層にも「リンバスって Unity だったんだ」という気づきが広がり、同時に Avapo! などの Unity 撮影ツールを使った VRChatter の作例が大量に流れた。インディー個人開発者の進捗ポストも非常に多く、全体としては「不安・愚痴・歓喜・進捗」が混在する、密度の濃い月曜だった。

2. 主なトピック・話題のクラスタ

2-1. 「Unity オワコン論」と Flash 比較

最大の議論クラスタ。mizchi 氏の連投が火元で、引用 RT・反論・便乗が一日中続いた。論点は「AI コーディング時代に GUI 中心の Unity は不利」「Godot のほうが軽くて AI と相性が良い」「Flash と同じ末路では」など。一方で「Flash が消えても HTML5 に移行できた、Unity もそうなるだけ」と冷静な反論も多数。

2-2. LimbusCompany Unity バージョンアップ告知

本日最大エンゲージメントは Project Moon 公式の Limbus Company における Unity エンジン更新告知 (1689 likes / 313 RT)。これにより「リンバスって Unity 製だったのか」「要求スペック上がるらしい」「ゲストアカウント喪失リスク」などの反応が連鎖した。商用タイトルにおける Unity 依存度の高さを改めて可視化した。

2-3. VRChat 向け Unity 撮影ブーム

Avapo! や PlayModeValueCapture、jonipon 氏のポーズツール (VRCAvatarposeeditor) など、Unity の Scene 内で直接アバター撮影をする文化が定着しつつある。「Unity 撮影覚えた」「VRC イン率減った」「ペアポーズが一人で撮れる」など、撮影体験の質的変化を語るポストが多い。

2-4. アバター改変・テスター募集

BOOTH 系の衣装作家がテスター（Unity 撮影・VRC 撮影が可能な改変ユーザー）を募るポストが大量に流れ、ミルティナ・ミルフィ・しなの・キプフェル・ショコラ・愛莉などのアバター名が頻出。「Unity 撮影で 4K 提出可」がほぼ標準スペックとして言及されている。

2-5. AI × Unity / Godot 移行論

Codex/Claude/ChatGPT を使った Unity 開発の感想ポストが多数。npaka123 氏が紹介した「プログラミング学習なしで AI でアクション RPG を 200 時間で作った」動画 (3492 views) が複数人に共有された。Godot 移行論も AI 文脈で語られ、「インタプリタ型でテキストベースだから AI 相性が良い」という認識が広まりつつある。

2-6. インディー開発の進捗報告

#Unity #ゲーム制作 タグで個人開発者の小粒な進捗が大量に投下されている。MagicaSoft の事前コンタクト生成機能 (517 likes)、AmeAxisGames のマウス操作対応、yamato_gk のバイサバ販売開始、cheese_tak の式神スキル開発 (61・62 日目) など、継続性のあるプロジェクトが目立つ。

2-7. Unity アセット・ツール紹介

Kan_Kikuchi 氏の True Shadow 記事、AssetLove 氏による HoloInterior Pro・Hierarchy Designer のセール紹介などが好反応。「$2 セールで全部買ったけど消化できない」系のジョークも見られた。

2-8. Switch 2 ローンチと Godot の現実

kraihd 氏が「Switch 2 ローンチに Unity/UE/Game Maker 製はあったが、初の Godot タイトルは半年遅れだった」と指摘 (231 likes)。Godot 推し論への現実的なカウンターとして拡散された。

5. バグ・不満・要望の傾向

具体的な技術的問題として頻出したのは：

  • VRChat SDK / アップロード関連：CMYN_VRC 氏の「SelectAvatar でサムネが変わらずアップロード失敗、毎回 Unity 再起動」、複数ユーザーの「アップロードボタンが反応しない」「鯖落ちでアップロードできない」報告。
  • プロジェクト破損・データ消失：「Unity 君が言うこと聞かない」「セーブ前にクラッシュ」「再起動したらシェーダ設定が飛んだ」など、月曜だけで 10 件以上の被害ポスト。Reiya__ 氏が「*.unity ファイル検索で復旧可能」と救済 Tips を流す場面も。
  • パフォーマンス：「学生 PC では Unity 起動できない」「複数起動でメモリ枯渇」「コンパイル待ち 1-5 秒」など、エントリー PC 層の悲鳴が顕著。Godot 流入の主要因として複数人が指摘。
  • シェーダー/見た目の差異：「Unity 上では問題ないのに VRChat だと色が違う」「ノーマルマップが平面的に見える」「裏面が暗くなる」など、Editor とランタイムの乖離問題。
  • Bakery 系：Kakuribbon 氏が「新しい Unity との不整合かバグ」と推定する事象を報告。
  • Unity AI 課金トラップ：jgame0807 氏が「解約画面に辿り着けず課金が始まった」と報告し、信用低下要素として共有された。

7. 商用/インディー/VRChat 別の動き

商用：LimbusCompany_B の Unity バージョン更新告知が圧倒的に話題。Honda X-Hub の Unity ベース XR プラットフォーム、ビーライズのデジタルツイン×スマートグラスなど、産業 DX 方面で Unity Japan が事例発信を継続。一方で powder0326 氏のように「Unity に軸足を置くとエンジニア生涯年収が下がる」という辛口意見もあり、商用エンジニア層の Unity 評価は割れている。

インディー：個人開発者は淡々と進捗を出している層が大多数。yamato_gk 氏の「バイサバ」BOOTH 販売開始、OYONElcad 氏の昭和ホラー『門 GATE』Steam ページ公開、welovegamesinc 氏の『CustomImageSurvivors』、ForestSnack 氏の無人島ゲーム、Acheron9436 氏の「2D 版崩壊スターレイル」など多彩。Godot 流入論には反応しつつも「とりあえず今のプロジェクトは Unity で作り切る」という現実的姿勢が主流。

VRChat：本日最も活発なクラスタ。Unity 撮影、アバター改変、衣装制作テスター募集、Booth 出品が主流。「Unity と殴り合う」「Unity と和解」「Unity に勝てますように」など、Unity を擬人化して語る独特な言語文化が極めて濃く、技術的にはギミック競合・Physbone・揺れ物・透過設定・スケール調整などのトピックが反復登場。Resonite/バーチャルキャストといった代替プラットフォームへの言及もあるが、VRChat における Unity の不可侵性は揺らいでいない。

モバイル/Web：mizchi 氏周辺の議論や ow54935 氏の「Unity でオープンワールド 2 年挫折、Flutter で 5 ヶ月で作り直してリリース」など、モバイル/Web 寄りの開発者ほど Unity 離れが起きている傾向が観察できる。Godot がモバイルで強くないという指摘 (wizamanwizaman) もあり、移行先も一枚岩ではない。
