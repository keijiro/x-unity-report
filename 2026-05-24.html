1. 全体サマリー

2026-05-24 の日本語 Unity 関連 TL は、午後から夕方にかけて VRChat 側で発生したサーバー障害 (Unity SDK にサインインできない / アバターアップロード不可) によって、改変勢の「Unity を開いたのにアップロードできない」という嘆きが大量に流れる一日となった。一方で、個人ゲーム開発勢は「Codex / Claude / Unity AI / MCP」を絡めた AI 駆動開発の話題で盛り上がり、ゲームエンジン論 (Unity vs Godot / Cocos) のスレッドも複数熱を帯びた。BitSummit PUNCH 関連ポストや、RPG ツクール新作「U2U」が Unity ベースであるという話題、Unity アセットストアの $2 セールなど、業界・ツール周りのニュースも多く、「VRChat 改変文化」「インディー開発」「商用エンジン論」の 3 層が並走する典型的な週末の風景である。

2. 主なトピック・話題のクラスタ

VRChat サーバー障害と Unity SDK サインイン不能

午後、VRChat 側の API 障害で VRCSDK にサインインできず、改変済みアバターのアップロードが軒並み止まった。「Unity 触れるけどアップロード出来ない」「鯖落ち？」というポストが大量発生し、改変モチベーションが空中分解した投稿者が続出。@uniumasugiru の見たことないエラー報告 (9920 views) など、初心者にとっては原因の切り分けすらできない状況だった。

RPG ツクール「U2U」が Unity ベースという話題

新作 RPG ツクール U2U が「Unity で作られた」だけなのか「Unity 上で動くツール」なのかで議論が起こり、後者と判明したことで「UNITE の悪夢」を思い出すユーザーが続出。一方で「Unity ベースなら UI 設定がグラフィカルで楽そう」と前向きな見方もあり、過去作 UNITE のトラウマと期待が混在している。

AI 駆動 Unity 開発 (Codex / Claude / Unity AI / MCP)

「プログラミング学習なしでスマホ用アクション RPG を作った」動画が複数人に共有され、参考になるという反応が広がった。Codex に Unity プロジェクトの性能改善や ML-Agents 学習を任せたり、Unity MCP でシーンを生成させたり、Antigravity を試したりという報告も多数。Unity AI のオープンベータ公開や、Light2DProvider 追加 (URP 17.5 / Unity 6.5) などの公式機能アップデートも流れた。

ゲームエンジン論争 (Unity vs Godot / Cocos)

Unity の価格改定騒動を引き合いに「素早く逃げ出さないと詰む」と語る @EzoeRyou のポストや、AI 活用勢が Godot や Cocos に移行しているという @AonekoSS の観察、UI を剥がせるかという議論など、エンジン乗り換えを巡るシリアスな対話が続いた。一方「Unity 永住の民」「Unity に戻ってきた」「アセット資産を捨てる勇気はない」など、留まる派の声も同程度に多い。

Unity アセットストア「Two Dollar Sale」

$2〜$4 で 90% 以上 OFF の Mega Bundle / City Pack / Industrial Props など、アセットセールの紹介ポストが多数。@patsupyon は「1,999 ドル得した」と大量購入を報告。VRChat ワールド制作・インディー開発の両層から「とりあえず買っておく」動きが見られた。

BOOTH 新作ギミック・アバター改変アセット

5. バグ・不満・要望の傾向

  • VRCSDK サインイン障害: 本日もっとも多発。Unity 側に責はないが、ユーザー体感としては「Unity が壊れた」と受け取られがち。
  • Editor のメモリ消費・重さ: 「起動しただけでメモリ食う」「32GB でもキツい」「Unity しながら VRC するとカクつく」など、Editor 肥大化への不満が複数。yhvh2525 は「Unity は多機能・高性能だが抱え込みすぎて肥大した」と分析。
  • マテリアル/シェーダー破損: PC フリーズ後に liltoon が消失、再インストールで復帰、という事例 (sol_tora, crossmozq)。Unity 画面と VRChat 内で見た目が違うという定番の悩みも複数。
  • Animator / Animation 関連クラッシュ: ps_kawasy の「Animator の矢印クリックで落ちる」「複数マテリアル同時切替で Unity が耐えられない」報告。
  • Blender → Unity の挙動差異: 「Blender では貫通してないのに Unity で貫通」「補助ボーンの回転制限」「humanoid 設定で薬指がねじれる」など、FBX 受け渡し周辺の罠が継続的に報告。
  • Unity AI Assistant の課金トラブル: OvlXU3paPB49540 が「無料体験終了後に自動課金されたがクレジット 0」と報告。
  • U:nity 製品ロゴ問題: Lichiphen が「あのロゴが出るのが嫌」と。
