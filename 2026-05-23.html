2026 年 5 月 23 日土曜日の日本語 Unity 関連ポスト群は、週末ということもあり VRChat アバター改変／Unity 撮影の話題が圧倒的なボリュームを占めた一方で、「#SuperDevDay (スーパー開発デー)」や「#プレミアムノベルゲ制デー」を冠したインディー開発勢の進捗報告も活発だった。話題面では BitSummit で発表された 「RPGツクールU2U」が Unity ベース継続 というニュース、AI コーディング (Claude / Codex / Gemini) と Unity の組み合わせに関する熱、そして「周りが Godot や Cocos に移行している」という他エンジン比較の議論が同時多発的に発生。全体としては「Unity と喧嘩した」「Unity 君と仲直り」というネガポジ混在の擬人化トーンが日本語 Unity コミュニティ特有の空気を作っており、技術的な深掘りと愛憎入り混じった日常ツイートが共存する典型的な週末となった。

5. バグ・不満・要望の傾向

不満ポストは Unity 本体の不安定さ・クラッシュ系と、VRChat SDK / ツール連携系に大別される。具体的には:

  • Unity クラッシュ・データ消失: アバターアップロード直前、ライトベイク中、外付け HDD 運用時など (@K3170VRC, @Mabu_VRC, @kuromomiz1)。
  • Unity 上では正常／VRChat 内では崩れる: 髪の浮き、表情、輪郭、ボーン挙動の差異 (@VRC_mi, @ei_ghtOo, @totomarulolicom)。
  • warudo SDK 指定の Unity 2021.3.45f2 が f1 しかない (@tammy_now) — バージョン固定の難。
  • Unity ワンタイムパスワードメールが届かない 不具合の同時多発報告 (@VRtibimarisa, @Popute_Ginga, @0m0iyako_jp)。
  • VRC World SDK 10.2 以降でメモリを食い潰しクラッシュするバグ (@taiyoukeee_v)。
  • Unity Asset Store の審査が異常に長い「余裕で 1000 アセット分待たされる」(@mitakamikata)。
  • AI がシェーダーグラフを正しく扱えない 報告 (@kojisato_50s)。
